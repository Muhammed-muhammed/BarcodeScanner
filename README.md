# 📷 Barcode Scanner React Component

A production-ready React component for scanning barcodes using the device camera. Built with **TypeScript**, powered by **@zxing/library**, and integrated with **Formik** for easy form management.

---

## 🚀 Features

- 🔍 Real-time barcode scanning via device camera
- 📦 Supports multiple formats (EAN, UPC, CODE_128, etc.)
- 🎯 Seamless integration with Formik forms
- 📱 Mobile-friendly and responsive
- ⚙️ Built with Create React App + TypeScript

---

## 🔧 How to Run

```bash
git clone <your-repo-url>
cd barcode-scanner-app
npm install
npm start
```

---

## 📷 Supported Formats

- EAN-13 / EAN-8
- UPC-A / UPC-E
- CODE-39 / CODE-128
- ITF / CODABAR
- DATA_MATRIX
- QR-CODE
